# 构图库 · composition-patterns

> 视频科普配图的 6 种基础构图模式。**一图一动作**，先选模式再填内容。

---

## 6 种基础构图

| # | 模式 | 适用场景 | 核心机制 |
|---|------|---------|---------|
| 1 | **钩子图（Hook）** | 视频开头 | 反常识 + 视觉冲突 |
| 2 | **数据对比（Compare）** | 数字 / 比例 / 量级 | 柱状 / 表格 / 跷跷板 |
| 3 | **流程机制（Process）** | 因果 / 步骤 / 转换 | 角色动手 + 箭头 |
| 4 | **排行榜（Rank）** | 行业 / 优先级 / 排序 | 递减柱 + 红 X |
| 5 | **反转对比（Twist）** | 反预期 / 视角转换 | 左右分屏 + 对比批注 |
| 6 | **金句字幕（Quote）** | 视频结尾 | **不进配图**（黑屏白字更稳） |

> **金句不进配图**——金句落到画面会"砸"，黑屏白字或语音旁白更稳。

---

## 模式 1 · 钩子图（Hook）

**目的**：抓住观众，制造"为什么"的认知冲突

**画面结构**：
- 左 / 主角色：反常识对象（巨大、夸张、矛盾）
- 中：喵博士（歪头、疑惑、嘴成 "?" 形）
- 散点：红色问号、橙色问号

**批注**：
- 🔴 红：核心反问（如"甜？？"）
- 🔵 蓝：核心数据 / 反常识事实（如"4-7% 蔗糖"）

**示例 prompt 骨架**：
> A [反常识对象] next to a puzzled 喵博士 with mouth forming "?", red annotation [反问]，blue annotation [数据]。

**校准**：`examples/images/01-hook.png`

---

## 模式 2 · 数据对比（Compare）

**目的**：让数字差"一眼看见"

**画面结构**：
- 三个或多个柱状 / 块状对象，高度差直接体现数据差
- 喵博士站在旁边（一爪指向关键柱）
- 数字标签直接写在柱顶

**批注**：
- 🔴 红：差距结论（如"6 倍差距"、"不到一半"）
- 🔵 蓝：横轴 / 类别标签（如"一亩地"、"含糖率"）

**构图变体**：
- 柱状对比（数量 / 高度）
- 跷跷板（一头沉一头翘）
- 两个方块 + 数字差（如"X10"）

**校准**：`examples/images/02-yield.png` / `03-sugar-rate.png`

---

## 模式 3 · 流程机制（Process）

**目的**：把抽象过程变成可视化操作

**画面结构**：
- 喵博士在做"工作"（拿工具、动手）
- 中间有"对象"被处理（被切开、被压缩、被过滤）
- 结果在另一边出现

**批注**：
- 🔴 红：能耗 / 代价（如"8 倍能耗"）
- 🔵 蓝：数量 / 阶段标签

**关键技巧**：
- 喵博士必须**拿工具**（扳手、放大镜、笔）——强化"在做事"感
- 物理动作必须**符合常识**（西瓜切开会滴水、过滤会留下滤渣）
- 避免"无形过程"——所有过程都要落地到一个物体

**校准**：`examples/images/04-extraction.png`

---

## 模式 4 · 排行榜（Rank）

**目的**：让"位置"和"被淘汰"一眼看见

**画面结构**：
- 多个柱状对象，**高度递减**
- 最右 / 最矮位置：被淘汰对象（标大红 X）
- 喵博士站在排行榜旁（一爪指 / 双手抱胸审视）

**批注**：
- 🔴 红：淘汰结论（如"连参赛资格都没有"）+ 红色 X
- 🔵 蓝：排行榜标题 / 行业标签

**关键技巧**：
- 柱子至少 3-4 个，否则不构成"榜"
- 红色 X 必须**醒目**（画大、画粗）
- 顶部 1-2 个柱要明显高于后面，形成层级感

**校准**：`examples/images/05-rank.png`

---

## 模式 5 · 反转对比（Twist）

**目的**：制造"原来如此"的视角转换

**画面结构**：
- 画面**分屏**（左右两半，中间一条线）
- 左：旧视角（被拒绝、被否定）
- 右：新视角（被接纳、被认可）
- 喵博士站在中间"懂了"的表情

**批注**：
- 🔴 红：右边的成功数据（如"上千亿流水"）
- 🔵 蓝：标题（"X vs Y"对比）

**关键技巧**：
- 左右用**同一种核心对象**（同一个西瓜/同一个方案）——强调"同一个东西在不同场景的命运"
- 右边必须**比左边视觉上更暖 / 更生动**（多画点东西：顾客、灯光、热闹）
- 左边要**有拒绝符号**（红 X、紧闭的门）

**校准**：`examples/images/06-twist.png`

---

## 模式 6 · 金句字幕（不进配图）

**金句 = 视频结尾旁白 + 黑屏白字字幕**，**不要做成图**。

理由：
- 画面会"砸"了金句的力量
- 黑屏白字更稳
- 视频剪辑时金句留出"画面停顿"更打动人

**金句应该**：
- 一句话
- 落点清晰（动词明确）
- 有反直觉的力量

## 选题决策流程

拿到一段文章 / 脚本，按以下顺序拆解：

```
1. 钩子是什么？（找反常识 / 反直觉点）
   → 模式 1

2. 主体由几段组成？
   - 多个数字 / 比例对比 → 模式 2
   - 多个步骤 / 因果 → 模式 3
   - 多个对象排序 / 淘汰 → 模式 4

3. 有反转 / 视角切换？
   → 模式 5

4. 文末金句？
   → 模式 6（黑屏字幕，不画图）
```

**最少 3 张，最多 8 张**。多了节奏拖，少了讲不透。

---

## 节奏建议

视频默认节奏：每张图配 5-8 秒旁白 + 1-2 秒停顿

```
[0:00] 模式 1（钩子）— 8 秒
[0:08] 模式 2（数据 1）— 6 秒
[0:14] 模式 2 或 3 — 6 秒
[0:20] 模式 3（流程）— 8 秒
[0:28] 模式 4（榜）— 6 秒
[0:34] 模式 5（反转）— 8 秒
[0:42] 黑屏金句 — 4 秒
```

总时长 ≈ 45 秒，适合短视频。
