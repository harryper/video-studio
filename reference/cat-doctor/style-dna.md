# 风格 DNA · ink-line

> v1.0 唯一支持的视觉风格。**这条底线**是整套配图的灵魂，所有 prompt 必须围绕它展开。

---

## 一句话定义

**纯白底 + 极简黑墨线 + 留白 + 少量红橙蓝中文手写批注 = 一图一动作的科普配图。**

怪诞但不卖萌，理性但不冷漠，工人感而不是装饰感。

---

## 必守规则（红线）

| 类别 | ✅ 必须 | ❌ 禁止 |
|------|--------|---------|
| **底色** | 纯白（#FFFFFF） | 纸纹、米色、阴影、渐变 |
| **线条** | 黑色细线、轻微抖动 | 粗描线、闭合完美的工业线 |
| **填色** | 不填色或仅极小色块（红/橙/蓝批注） | 复杂色块、面填色、阴影渲染 |
| **留白** | 主体只占 30-50% 画面 | 满构图、拥挤 |
| **批注颜色** | 仅红 / 橙 / 蓝 三色手写中文 | 其他颜色、印刷字、装饰图案 |
| **角色占比** | 角色是 worker，不是装饰品；必须参与核心动作 | 角色站在角落纯装饰 |
| **复杂度** | 一图只讲一个核心动作 / 结构 / 状态 / 隐喻 | 多动作堆叠、说明书式 |

## 视觉 DNA 拆解

### 1. 画布

- 比例：**16:9 横版**（默认）
- 底色：纯白，无任何纹理
- 主体位置：偏左或偏中（不要正中），给批注留空间

### 2. 线条

- 颜色：纯黑（#000000）或近黑深灰
- 粗细：细线（1-2px 等效），所有线条粗细一致
- 风格：手绘、有轻微抖动、不完全闭合（真实手绘感）
- 禁止：粗描线、矢量完美线、装饰花纹

### 3. 填色

- **主体（角色 + 道具）：不填色**——只保留线条
- **批注文字：可使用红/橙/蓝**
  - 红色 `#E74C3C`：强调、警告、否定（"X"、"连参赛资格都没有"、"8 倍能耗"）
  - 橙色 `#F39C12`：次要强调（"？"、箭头）
  - 蓝色 `#3498DB`：中性信息、标签（"一亩地"、"含糖率"）
- 批注文字必须是**手写感**（不是印刷体）

### 4. 留白

- 主体只占画面 30-50% 面积
- 留白 = 50-70%
- 留白不是空的，是"思考空间"

### 5. 角色定位

- 角色 = 怪诞工人，正在参与核心动作
- 角色 = 工具人，不是主角；信息才是主角
- 如果去掉角色画面仍然完全成立 → **角色太装饰了，必须重做**

## 批注规范（重要）

批注是这个风格的**核心信息载体**，写好批注就成功一半。

### 三色分工

| 颜色 | 用途 | 典型词 |
|------|------|--------|
| 🔴 红 | **结论 / 警告 / 否定 / 数字冲击** | "6 倍差距"、"X"、"连参赛资格都没有" |
| 🟠 橙 | **疑问 / 引导 / 中度强调** | "？"、"甜？？"、"为什么" |
| 🔵 蓝 | **标签 / 标题 / 中性信息** | "一亩地"、"含糖率"、"制糖 vs 鲜食" |

### 批注位置

- 紧贴被标注对象（柱状图、对象、动作）
- 字号比正文小，**手写感**
- 一张图批注不超过 **3-5 个**，多了会乱

### 批注 vs 文字

- ❌ 不要：长句解释、段落式文字
- ✅ 推荐：单词、短语、数字、符号
- 中文为主，必要时混入少量英文（"FOR SALE"）

## 物理隐喻（关键技能）

这个风格最强的能力是**把抽象概念变成怪诞的物理隐喻**。举例：

| 抽象概念 | 物理隐喻 |
|---------|---------|
| 信息过载 | 一个井里塞满信息 / 信息井 |
| 想法压实 | 一台想法压机 / 把想法压成砖头 |
| 信任建立 | 一座桥 / 一块块证据铺过去 |
| 内容发酵 | 酿酒桶 / 发酵罐 |
| 浪费 | 一车水在倒 / 90% 载重在拉水 |
| 成本高 | 跷跷板一头沉一头翘 |
| 失败 | 被拒收 / 被划掉 / 被踢出 |
| 优先级 | 排队 / 排行榜 |

**原则**：低科技、怪诞但成立、视觉上立刻可读。

---

## 反例（避免的画风）

- ❌ 精致扁平插画（Headway / Notion 风格）
- ❌ 商业插画（品牌 KV）
- ❌ 复杂信息图（PPT 风格流程图）
- ❌ 儿童卡通、可爱 IP、表情包
- ❌ 大段文字型信息图
- ❌ 萌系 Q 版（大眼、腮红、大头小身）
- ❌ 拟真照片 / 3D 渲染

## 自检清单

出图后过一遍：

- [ ] 纯白底？（不能有纸纹 / 米色 / 渐变）
- [ ] 主体只占 30-50% 画面？
- [ ] 主体没填色？（只有黑线）
- [ ] 批注只有红 / 橙 / 蓝？
- [ ] 批注是手写感？
- [ ] 一图只讲一个核心动作？
- [ ] 角色参与核心动作，不是装饰？
- [ ] 抽象概念被翻译成了物理隐喻？

如有任一项不通过，**重新出图**。
