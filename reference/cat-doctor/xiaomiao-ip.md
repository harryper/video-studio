# 喵博士 IP 协议 · xiaomiao

> v1.0 唯一支持的视觉 IP。**这个角色的视觉一致性是整个 Skill 复用的关键**。

---

## 一句话定义

**喵博士** = 一只戴单片眼镜 + 蝴蝶领结的简笔小猫，**怪诞工人感，不卖萌**。它是"在认真参与系统运转的荒诞工作者"，不是吉祥物、不是贴纸、不是站在角落里的装饰物。

---

## 必守规则

| 类别 | ✅ 必须 | ❌ 禁止 |
|------|--------|---------|
| **物种** | 简笔小猫（圆头 + 三角耳） | 写实猫、Q 版萌猫、其他动物 |
| **大小眼** | 两小圆点眼（直径 ≈ 头部 5%） | 大眼、闪亮高光眼、闭眼 |
| **表情** | 简笔小嘴（一条短线 / 小 o 形） | 复杂表情、卖萌表情、夸张表情 |
| **身份符号** | **单片眼镜（吊金链）+ 蝴蝶领结** | 戴全框眼镜、不戴眼镜、戴领带 |
| **身体比例** | 头身比约 1:1（不是 Q 版大头小身） | 大头小身萌版、瘦长写实版 |
| **身体** | 简笔人形躯干（不强调曲线） | 拟真肌肉、卡通大眼睛 |
| **气质** | 怪诞工人感（认真、稍微荒诞） | 卖萌、可爱、装饰化 |
| **配饰** | 仅单片镜 + 蝴蝶领结 | 帽子、围巾、衣服（v1.0 不要加） |

---

## 招牌识别元素（绝不能丢）

这两个是"**一眼认出喵博士**"的关键：

1. **单片眼镜 + 金链**——右眼位置、圆形镜面、细金链垂到胸前
2. **蝴蝶领结**——脖子位置、不大不小、略卡通

> **不要**用"全框眼镜"、"双片眼镜"、"大墨镜"——一旦改了，识别度立刻崩。
> **不要**用"领带"、"西装领"——调性不对，喵博士是工人不是总裁。

---

## 角色动作谱

喵博士不是静态装饰品，必须**参与核心动作**。常见动作：

| 动作 | 适用场景 |
|------|---------|
| 拿工具（扳手、放大镜、笔、尺子） | 工人感、做事中 |
| 指向某物（一爪指着） | 标注、解释 |
| 歪头看 / 头倾斜 | 思考、疑惑、发现 |
| 双手抱胸 / 一爪叉腰 | 判断、审视 |
| 拿空钱包 / 捂心口 | 心疼、亏损、成本 |
| 站在两个对比场景中间 | 反转、双面性 |
| 单手托下巴 / 摸下巴 | 思考中 |
| 表情空白 / 微张嘴 | "啊原来如此" |

## Prompt 必带修饰词

每张图只要画喵博士，prompt 中必须包含以下关键词（顺序无关）：

```
- simple small anthropomorphic cat character
- round head, two small triangle ears
- two small dot eyes
- single small round monocle on a thin gold chain
- small bowtie collar
- drawn in the style of a quirky worker
- not cute, not childish
```

**禁止**使用：
- ❌ big round sparkly eyes（大眼萌系）
- ❌ blush cheeks / pink cheeks（腮红）
- ❌ kawaii（萌系风格词）
- ❌ chibi / Q-version（Q 版风格词）
- ❌ cute / adorable（萌系）

## 角色一致性自检

出图后必查：

- [ ] 是单片眼镜（不是双片）？
- [ ] 有蝴蝶领结（不是领带、不是西装）？
- [ ] 眼是小圆点（不是大眼）？
- [ ] 头身比 ≈ 1:1（不是大头萌版）？
- [ ] 表情不卖萌（不咧嘴笑、不眨眼）？
- [ ] 角色正在做事（不是呆呆站着）？
- [ ] 配饰只有镜 + 领结（没有帽子/围巾/衣服）？

如有任一项不通过，**重新出图**。
